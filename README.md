# Tech Support Tools

A monorepo containing utilities and scripts for IT support specialists and help desk professionals.

## Structure

```
tech-support-tools/
├── tools/           # Individual tool directories
│   ├── windows/     # Windows-specific utilities
│   ├── macos/       # macOS-specific utilities
│   ├── linux/       # Linux-specific utilities
│   └── cross-platform/  # OS-agnostic tools
└── docs/            # Documentation
```

## Planned Tools

- **System Diagnostics** - Hardware/software inventory and health checks
- **Network Utilities** - Connectivity tests, DNS troubleshooting, port scanners
- **User Management** - Account audits, password resets, permission checks
- **Remote Support** - Session logging, remote access helpers
- **Log Analysis** - Parse and filter system/application logs
- **Batch Scripts** - Common automation tasks for deployment and maintenance
- **Ticket Helpers** - Templates, quick responses, categorization aids

## Getting Started

Each tool will have its own README with specific installation and usage instructions.
